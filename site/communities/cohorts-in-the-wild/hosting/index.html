Self-hosted computer

Connect a self-hosted World

The agent makes outbound HTTPS reports only. It does not open your router, accept remote shell commands, or expose your home network.

Only use this for a game running on a computer you control. If you want to add an existing Community's map—such as Cohorts in the Wild · Genesis—to a Discord server you manage, you do not need the Host Agent. Choose an existing Community and map
  1. Download the Trog Host Agent onto the computer hosting the game.
  2. Choose Create pairing command below.
  3. Run the one-time command on that computer, then run python3 trog_host_agent.py run.

Nitrado

Connect your Nitrado account

This takes about two minutes. Trog receives access to game services only.

  1. Sign in to Nitrado, then open the hidden long-life token page.
  2. Enter a description such as Trog.
  3. Check only service. Do not select rootserver, user, ordering, or SSH permissions.
  4. Choose Create. Your token appears once as green text at the top of the page.
  5. Copy the entire green token immediately, return here, and paste it below.

Trog encrypts the token and never shows it again. You can revoke it from Nitrado at any time.

Disconnecting removes the stored credential and local bindings. Revoke the long-life token separately in Nitrado to invalidate it at the provider.
